Проблема получения данных от сервера (веб сервиса)
Как вызвать? Либо Fetch API или HttpClient

Возникает проблема: современный Ангуляр не уведомляет 
автоматически шаблоны об изменениях полей класса.
Решение: либо signal, либо ChangeDetectorRef

Где реализовывать вызов вебслужбы?
Либо в ngOnInit компоненты, либо в отдельном инжектируемом сервисе

В разных сочетаниях эти решения применены 
в компонентах cbr..cbr4 на примеры вызова веб службы ЦБР

Дополнительно: Как одна компонента может уведомить другие компоненты 
о чем-то и передать данные (послать "сообщения")? 
Решение: см. компоненты cbr (отправитель), indicator (подписчик)
и сервис broker.
