Один раз: npm install -g @angular/cli
Сделать проект: ng new ya02_hello
В консольном диалоге выбрали тривиальный CSS и отказались от Server Side Rendering
Перейти в папку ya02_hello и запустить ng serve
Или открыть эту папку в VS Code. (И поставить туда расширение Angular Language Service)
Смотреть в браузере http://localhost:4200

Далее разбираться с файлами, из которых состоит компонента: 
app.ts, app.html, app.css

Дополнительно можно добавить сервисы, инжектируемые через DI. 
Инжекцию можно предписать в нескольких разных местах (см.комментарии в app.ts)
