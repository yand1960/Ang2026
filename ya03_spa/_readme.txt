Добавить компоненту: ng generate component page1

Компонента app - корневая. 
Вывести одну компненту внутрь другой - добавть в шаблоне 
родительской компоненты <app-page1></app-page1>.Бывает, но редко.

Оптимальный вариант: добавить маршруты в app.routes.ts.
Тогда при щелчке на гиперссылке компонента будет появляться в <route-outlet>.

Чтобы получать настоящий SPA (без обращения к серверу), 
в гиперссылках в панели навигации вместо атрибута href следует использовать routerLink.
